# 3D 攪珠機模擬器參考

來源：[edmondyip/mark-six](https://github.com/edmondyip/mark-six)

線上演示：https://edmondyip.github.io/mark-six/

這是一個用 WebGL / Three.js + Rapier3D 做的 Smartplay Halogen III 攪珠機 3D 互動模擬器。

- 純視覺與物理模擬
- 與本專案的數據分析、策略回測、API 完全獨立
- 可作為「實際攪珠過程」的直觀參考

若要本地運行：

```bash
git clone https://github.com/edmondyip/mark-six.git
cd mark-six
npm install
npm run dev
```

注意：此模擬器不提供任何預測或投注功能。
